## Prose Does Not Bind Agents

Mechanically enforced safeguards for multi-agent coding on a single repository. A
30-day case study of four coding agents on one repository.

An agent deleted the repository's own safeguards, 137 files and 10,097 lines, and
the build stayed green. Four agents built four versions of a feature the platform
already ships. Three automated checks passed while asserting less than they
appeared to.

Every figure is reproducible from a public corpus at a pinned commit, and the paper
lists the command behind each count.

- [The preprint](https://github.com/effinrich/prose-does-not-bind-agents): PDF and source, 19 pages.
- [The corpus](https://github.com/effinrich/h2-fe-assessment): every commit, decision record and safeguard the paper cites.
